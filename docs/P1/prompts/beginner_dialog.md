## 个人反思

### 哪个 Prompt 效果最好？

本阶段只有一个核心 Prompt，就是围绕“按 IEEE 830 格式完善需求规格说明书”的这个对话。
它最大的作用是帮助我快速搭建正式文档内容，尤其是在需求模块划分、编号整理和追踪矩阵补全方面比较有帮助。

### 踩过什么坑？

1. **AI 容易输出过于泛化的需求文档**
   如果不加限制，AI 会写得很完整，但不一定符合课程项目的实际范围，需要我再按 P0 / P1 / P2 手动收缩。

2. **AI 不会自动知道哪些内容是模板、哪些内容是最终交付物**
   仓库里原本已经有模板文件，但 AI 默认会把它当成“现成文档”，所以需要我自己区分哪些是初始化内容，哪些才是任务二真正完成的内容。

3. **AI 输出能作为基础，但不能直接交**
   尤其是来源标注、校园场景细节、优先级判断、是否符合课程要求，这些都还是要人工把关。

### 下阶段 Prompt 改进方向

1. 在 Prompt 里明确说明“这是在已有模板基础上完善，而不是从零生成”，减少 AI 误判上下文。
2. 提前写清楚“只做当前成员负责的任务”，避免把别人的任务内容混进自己的对话记录里。
3. 后续继续采用“先给格式要求，再给范围约束，再让 AI 输出”的方式，这样结果更稳定。
