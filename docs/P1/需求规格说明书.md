## 1. 引言

### 1.1 目的

本文档描述 CampusHub 校园综合服务平台的功能需求和非功能需求，为开发团队提供明确的开发目标，为测试团队提供验收依据。

### 1.2 范围

CampusHub 是一个面向大学生的校园互助服务平台，支持用户发布互助需求、浏览需求、接单协作、完成订单、进行评价，并逐步扩展至学习辅导、二手交易、组队匹配等场景。

### 1.3 定义

| 术语   | 定义                               |
| ------ | ---------------------------------- |
| 发布者 | 在平台上发布互助需求的用户         |
| 接单者 | 接受并完成互助需求的用户           |
| 管理员 | 负责平台审核、用户管理与统计的角色 |
| 订单   | 从接单到完成评价的一次完整互助流程 |
| 信用分 | 用户信誉评价体系                   |

- IEEE Std 830-1998, IEEE Recommended Practice for Software Requirements Specifications
- 本阶段用户调研报告
- P1 需求分析任务说明

## 2. 总体描述

### 2.1 产品视角

CampusHub 是一个 Web 应用，采用 Vue3 + JavaScript 技术栈，为大学生提供便捷的校园互助服务。平台核心目标是把分散在微信群、QQ群、校园墙中的互助需求统一到一个系统中，提高匹配效率并增强信任保障。

### 2.2 用户特征

| 用户类型   | 特征描述                                       |
| ---------- | ---------------------------------------------- |
| 普通学生   | 主要使用快递代取、信息问答、二手交易等功能     |
| 服务提供者 | 愿意在顺路、耗时少、有一定回报的情况下帮助他人 |
| 管理员     | 负责需求审核、用户管理和平台秩序维护           |

### 2.3 约束

- 开发周期：10 周
- 技术栈：Vue3 + JavaScript
- 预算限制：学生项目，优先使用免费服务
- 必须优先完成用户管理、需求发布与浏览、订单流程管理等核心功能

### 2.4 假设

- 用户拥有智能手机和校园网络
- 用户愿意进行实名认证或学号绑定
- 学校允许校园内部互助类平台运行
- 平台主要面向校内真实用户，不考虑复杂的跨校场景

## 3. 功能需求

说明：以下需求均按课程要求标注来源，来源分为 `[AI生成]`、`[人工补充]`、`[AI生成+人工修改]`。

### 3.1 用户管理模块

#### FR-001 用户注册

- **描述：** 用户可通过学号和密码注册账号
- **优先级：** Must
- **来源：** [AI生成+人工修改]

#### FR-002 用户登录

- **描述：** 支持学号+密码登录
- **优先级：** Must
- **来源：** [AI生成+人工修改]

#### FR-003 实名认证

- **描述：** 用户需完成实名认证或学号绑定后才能发布需求或接单
- **优先级：** Must
- **来源：** [人工补充]

#### FR-004 个人资料管理

- **描述：** 用户可维护头像、昵称、学院、联系方式等个人资料
- **优先级：** Must
- **来源：** [AI生成+人工修改]

#### FR-005 角色切换

- **描述：** 同一用户可在发布者和接单者两种角色之间切换
- **优先级：** Must
- **来源：** [AI生成+人工修改]

---

### 3.2 需求发布与浏览模块

#### FR-006 发布互助需求

- **描述：** 用户可填写标题、描述、分类、地点、时间、报酬或交换条件后发布需求

- **来源：** [AI生成+人工修改]

#### FR-007 需求分类

- **描述：** 系统支持快递代取、学习辅导、二手交易、活动组队、信息咨询等分类

- **来源：** [人工补充]

#### FR-008 浏览需求列表

- **描述：** 用户可浏览平台中的互助需求列表
- **优先级：** Must
- **来源：** [AI生成]

#### FR-009 查看需求详情

- **描述：** 用户可查看需求的详细信息，包括描述、发布者、地点、时间、报酬和状态
- **优先级：** Must
- **来源：** [AI生成+人工修改]

#### FR-010 条件筛选

- **描述：** 支持按关键词、分类、时间、距离等条件筛选需求
- **优先级：** Must
- **来源：** [AI生成+人工修改]
