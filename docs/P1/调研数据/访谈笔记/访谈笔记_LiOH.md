# 调研对话

> 调研人：LiOH 
> 日期：2026.4.16 
> 调研目标：了解校园互助的真实需求场景

用户访谈

**背景了解**

1. 请简单介绍一下您的年级和专业，日常使用的社交平台？
答：
年级：大一
专业：计算机科学与技术
社交平台：日常最常用的平台是 B站、微信qq。校内信息主要还是靠微信群和校园墙。

**痛点挖掘**

2. 在校园生活中，有没有什么事情让您觉得"要是有人能帮个忙就好了"？能具体说说吗？
答：
挺多的。快递点太远（尤其是大件包裹）拿不动；还有就是做期末课题之类的需要临时找人帮忙，找熟人怕欠人情，找陌生人又没渠道；平时有些关于学校或者学业的问题也不方便提问

3. 您现在是怎么解决这类需求的？（微信群、论坛、朋友帮忙等）这些方式有什么不方便的地方？
答：
主要是加各种 QQ 群（新生群、技术交流群）或者在校园墙投稿。不方便： QQ群消息刷得飞快，提个技术问题很快就被表情包淹没了，而且没人有义务一直盯着群看;校园墙效率太低，等墙发出来可能已经是第二天了，急事儿根本指望不上。

**场景探索**

4. 如果有一个专门的校园互助平台，您最希望在上面做什么？为什么？
答：
最希望看到实时任务。比如我想去拿快递，顺便看看有没有人也要拿，我帮他带回来赚个几块钱；或者我不想动的时候，发个单子有人接。然后偶尔提些问题。

5. 您会愿意在平台上帮助别人吗？什么情况下愿意，什么情况下不愿意？
答：
愿意： 只要是顺便的事。比如我刚好要去食堂，帮人带个饭完全没问题；或者是我在路上闲逛，帮人指个路。不愿意： 需要特意跑一趟、很费时间的事情，或者是那种看起来很奇怪、涉及隐私的要求。

**安全顾虑**

6. 使用陌生人互助服务时，您最担心什么？什么样的机制能让您放心使用？
答：
担心： 主要是怕遇到校外的人，不安全。或者是东西带回来了，对方却不给钱。机制： 必须得是实名认证，最好能显示对方的院系。另外最好有平台的资金托管，事儿办完了再确认收货。

**竞品反馈**

7. 您用过闲鱼、校园表白墙之类的平台吗？体验如何？你觉得分别有什么缺点和优点？
答：
校园墙： 优点是大家都在看，很热闹；缺点是太乱了，找个帮忙的信息得翻半天，效率极低。闲鱼： 优点是买卖东西很正规；缺点是大多是校外交易，鱼龙混杂。

**期望收集**

8. 您理想中的校园互助平台应当有什么特点？为什么？
答：
消息能秒发秒回，审核快一点。确定对方真的是本校同学，交流起来没隔阂。有标签化索引。没广告。
